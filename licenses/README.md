# 라이선스 사본

배포물에 싣는 글꼴과 upstream 의 라이선스 전문을 upstream rhwp v0.9.1
(커밋 981ce66b4183b13c1a3b5907e04a8969c8c42034) 에서 그대로 옮겨 둔 것이다.
배포물에는 빌드할 때 upstream 에서 같은 파일을 가져와 `fonts/licenses/` 와 `licenses/` 에 싣는다.

- `rhwp-LICENSE.txt`: rhwp MIT 라이선스
- `fonts/`: 배포하는 글꼴의 라이선스 전문 (SIL OFL 1.1, GUST Font License, LPPL 1.3c) 과 upstream 의 글꼴 고지 안내(README.md)

카페24 써라운드, 카페24 슈퍼매직, 해피니스 산스의 라이선스 PDF 는 그 글꼴을 싣지 않으므로 넣지 않았다.
